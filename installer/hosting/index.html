Before you start

The installer downloads the latest stable release. If downloads are unavailable, check the releases page and try again after an installer release has been published.

You need a running Linux Docker daemon, Docker Compose v2 and at least 8 GiB of free disk space. The installer detects your system and shows Docker installation instructions if needed. Only architectures approved by the selected release can be installed.

The installation uses ~/.sterracode and port 3000 by default. You can choose a LAN address. No firewall or router settings are changed.

Updates on your terms

SterraCode shows available updates after you sign in. Install with one click, or enable automatic updates, including compatible major releases, in a maintenance window. Automatic updates start disabled.

The separate updater has Docker daemon access to replace containers and make recovery backups. The application and code runner have no Docker socket access.

Already running SterraCode?

The installer preserves installations created with these scripts. Source-based installations require an explicit, backed-up migration; they are never silently taken over.
