# Begriffe der drei Produktsprachen

Stand: 20.10.2026. Dieses Glossar dokumentiert die tatsächlich vorhandenen deutschen, englischen und spanischen Katalogtexte. Es ergänzt Etappe 0 des [Umstellungsplans](../../I18N-UMSTELLUNGSPLAN.md). Es ändert keine Übersetzung und benennt keine gespeicherten Felder um. Die Schlüssel sind die gemeinsamen Belege für die jeweilige Zeile in [Deutsch](../../shared/i18n/locales/de/), [Englisch](../../shared/i18n/locales/en/) und [Spanisch](../../shared/i18n/locales/es/).

| Begriff und Bedeutung                                         | Deutsch            | English          | Español               | Katalogbeleg                                                                                                                   |
| ------------------------------------------------------------- | ------------------ | ---------------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Session: abgegrenzter Lernverlauf mit eigenen Dateien         | Session            | Session          | Sesión                | `sessions:new.title`: „Neue Session“ / „New session“ / „Nueva sesión“                                                          |
| Workspace: Dateien und Arbeitsbereich der Session             | Workspace          | Workspace        | Espacio de trabajo    | `app:static.workspaceLabel`                                                                                                    |
| Lernplan: Themenfolge einer Session                           | Lernplan           | Learning plan    | Plan de aprendizaje   | `app:static.plan`                                                                                                              |
| Lernprofil: freiwillige, sessionübergreifende Lernbelege      | Lernprofil         | Learning profile | Perfil de aprendizaje | `app:static.profile`                                                                                                           |
| Aufgabe: konkrete Lernaufgabe                                 | Aufgabe            | Task             | Tarea                 | `features:chat.newTask`: „Neue Aufgabe“ / „New task“ / „Nueva tarea“                                                           |
| Wiederholung: freiwillige erneute Übung eines Konzepts        | Wiederholung       | Review           | Repaso                | `features:profile.startReview`: „Wiederholung starten“ / „Start review“ / „Iniciar repaso“                                     |
| Vorschlag: noch nicht angewandte Dateiänderung                | Vorschlag          | Proposal         | Propuesta             | `features:diffInspector.proposal`; Abgrenzung in `features:diffInspector.historyHelp`                                          |
| Übernehmen: ausgewählte Dateiänderungen anwenden              | Auswahl übernehmen | Apply selection  | Aplicar selección     | `features:diffInspector.apply`                                                                                                 |
| Rückgängig: eine bereits erfolgte Änderung zurücknehmen       | Rückgängig         | Undo             | Deshacer              | `features:shared.undo`                                                                                                         |
| Ausführung: Programmlauf; getrennt von fachlicher Beurteilung | Ausführung         | Execution        | Ejecución             | `features:errorCatalog.execution`: „Ausführung / Infrastruktur“ / „Execution / infrastructure“ / „Ejecución / infraestructura“ |
| Snapshot: gespeicherter, zeitlich festgelegter Quellstand     | Snapshot           | Snapshot         | Instantánea           | `features:preview.snapshot_one`; `features:taskTests.sources`                                                                  |

Die deutsche Workspace-Navigation heißt in `app:static.workspace` weiterhin „Arbeitsplatz“; ihr zugänglicher Bereichsname lautet „Workspace“. Beides bezeichnet denselben Arbeitsbereich. Die deutschen Einstellungen `app:settings.crossProfile` und `app:settings.updateProfile` behalten den bisherigen Ausdruck „Sprachprofil“. Gemeint ist fachlich das Lernprofil je **Programmiersprache**, nicht eine Oberflächen- oder Tutorsprache. Die englischen und spanischen Einträge verwenden dort bereits „learning profile“ beziehungsweise „perfil de aprendizaje“.

„Review“ besitzt zwei Kontexte: Eine freiwillige Lernwiederholung heißt auf Englisch „review“ und auf Spanisch „repaso“. Der technische Änderungsmodus `app:settings.review` behält dagegen den sichtbaren Modusnamen „Review“ in allen drei Sprachen mit einer erklärenden Ergänzung („vor Übernahme prüfen“ / „check before applying“ / „revisar antes de aplicar“). Das ist weder ein anderer Aufgabenstatus noch eine Umbenennung der maschinellen Moduskennung. Für das Prüfen einer Aufgabe verwendet `features:chat.reviewTask` „Aufgabe prüfen lassen“ / „Ask for task review“ / „Pedir la revisión de la tarea“.

## Getrennte Sprachbegriffe

| Auswahl                 | Deutsch            | English              | Español                  | Beleg und Wirkung                                                                                                                                                                |
| ----------------------- | ------------------ | -------------------- | ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Oberfläche              | Oberflächensprache | Interface language   | Idioma de la interfaz    | `common:locale.label`; `uiLocale` gilt browserlokal für Beschriftungen und eigene Meldungen.                                                                                     |
| Tutor                   | Tutorsprache       | Tutor language       | Idioma del tutor         | `sessions:tutor.label`; `session.tutorLocale` steuert zukünftige Tutorantworten. Der sichtbare Tutor heißt `app:static.tutor`: „KI-Tutor“ / „AI tutor“ / „Tutor de IA“.          |
| Programmiersprache      | Programmiersprache | Programming language | Lenguaje de programación | `app:static.programmingLanguage`; bestehende `session.language`-/`allowedLanguages`-Werte wie Python oder JavaScript bleiben fachliche Kennungen.                                |
| Materialisierter Inhalt | Inhaltssprache     | Content language     | Idioma del contenido     | Begriff belegt durch `learningContent:errors.locale`; `contentLocale` hält die Herkunft neu erzeugter Vorlagen und Offlineaufgaben fest. Er übersetzt keine vorhandenen Dateien. |

Die tatsächlichen Anzeigenamen der Auswahl sind „Deutsch“, „English“ und „Español“ aus der [Locale-Registry](../../shared/i18n/locale.js); die zugehörigen Formate sind `de-DE`, `en-GB` und `es-ES`. `formatLocale` ist eine abgeleitete Darstellungseinstellung, keine zusätzliche Programmiersprache oder Zeitzone. Der historische Tutorwert `null` heißt `sessions:tutor.legacy`: „Sprache des Nutzers (bisheriges Verhalten)“ / „User’s language (legacy behaviour)“ / „Idioma del usuario (comportamiento anterior)“.

Spanische Produkttexte verwenden die direkte Ansprache mit `tú`; zum Beispiel „Selecciona“, „Abre“ und „Dame“ in den tatsächlichen Handlungstexten. „Prueba“ bezeichnet einen fachlichen Test, „repaso“ die freiwillige Wiederholung und „revisión“ die Prüfung einer Aufgabe oder Änderung. Die Begriffe sind dadurch nicht allein aufgrund eines ähnlichen englischen Ausgangsworts austauschbar.

Technische IDs, Toolnamen, Dateipfade und die erwarteten Rückgabewerte des Zahlenratespiels bleiben unverändert. Alte Nutzertitel, Lernziele, Chatantworten und materialisierte Aufgaben behalten ihre Originalsprache. Die Einzelheiten dieser Herkunftsgrenzen stehen in [INHALTE.md](INHALTE.md) und [SERVER-TEXTFLUESSE.md](SERVER-TEXTFLUESSE.md).
